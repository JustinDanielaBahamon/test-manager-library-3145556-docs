# Stack mapping — Python plan to Laravel + React

Source: [`../spec-python/plan.md`](../spec-python/plan.md) §1 and [`../spec-python/architecture.md`](../spec-python/architecture.md).
Only the technology changes; the reason column of the original plan still applies.

## 1. Technical decisions

| # | Python decision | Laravel / React decision | Notes |
|---|---|---|---|
| D-01 | Python 3.12 | PHP 8.3 + Laravel 11 | Challenge stack |
| D-02 | FastAPI | Laravel HTTP layer (routes `routes/api.php`, prefix `/api/v1`) | Contract in `api-contract.md` is kept as is |
| D-03 | SQLAlchemy 2 + Alembic on PostgreSQL 16 | Laravel migrations + query builder/Eloquent on PostgreSQL 16, schema `library` | Schema owned by migrations (ADR-001) |
| D-04 | Version token + `CHECK` | Atomic conditional update + `CHECK ck_book_available_range` | See `spec-gaps.md` G-1 |
| D-05 | UTC instants, `Clock` port | `Clock` port (interface) with a system implementation and a fake for tests | Columns `timestampTz`; app timezone `UTC` |
| D-06 | Aggregated query through a read port | `ReportReader` port implemented with one SQL aggregate query | ADR-004 |
| D-07 | Value objects `Isbn`, `Quantity`, `DocumentNumber`, `DateRange` | Same value objects as plain PHP `final readonly` classes | No tables |
| D-08 | Covers on disk / S3, DB keeps `cover_key` | `CoverStorage` port implemented with Laravel `Storage` (local disk) | Opaque key, never a path |
| D-09 | Argon2id behind `PasswordHasher` | `PasswordHasher` port implemented with `password_hash(..., PASSWORD_ARGON2ID)` | Domain never sees plain text |
| D-10 | Initial admin from `ADMIN_USERNAME` / `ADMIN_PASSWORD` | Same, created on boot by an artisan command run by the container entrypoint | DB never seeds a hash |
| D-11 | JWT HS256, 8 h, `JWT_SECRET` | `TokenIssuer` port implemented with `firebase/php-jwt` (HS256, 8 h, claims `sub` and `role`) | No personal data in the token |
| D-12 | pytest with fakes | PHPUnit (or Pest) with fakes for ports; real PostgreSQL only in integration tests | Same test pyramid |
| — | (frontend) | React + Vite, React Router | Vite default origin `http://localhost:5173` matches `CORS_ORIGIN` example |

## 2. Hexagonal layout in Laravel

```text
app/
├── Domain/                  # Book, Loan, LoanItem, Member, User; Isbn, Quantity, DocumentNumber, DateRange
│                            # plain PHP only: no Illuminate\*, no Eloquent (Article I)
├── Application/
│   ├── Ports/               # BookRepository, LoanRepository, MemberRepository, UserRepository,
│   │                        # ReportReader, Clock, PasswordHasher, TokenIssuer, CoverStorage
│   └── Services/            # LendBooksService, ReturnItemService, CreateBookService, SearchBooksService,
│                            # OverdueService, MostBorrowedReportService, LoginService, CreateLibrarianService
├── Adapters/
│   ├── Http/                # controllers, request validation, error rendering, role middleware
│   └── Persistence/ Storage/ Security/
└── Providers/
    └── PortBindingsServiceProvider.php   # the single composition point (Article III)
```

## 3. How each article of the constitution is verified in Laravel

| Article | Python verification | Laravel verification |
|---|---|---|
| I — Domain depends on nothing | `import-linter` + test | Architecture test (Pest `arch()` or a PHPUnit test scanning `use` statements): `App\Domain` only uses PHP core |
| II — Ports declared by the core | `import-linter` + test | Architecture test: `App\Application` does not use `App\Adapters` |
| III — One composition point | Test | Architecture test: adapter classes are only referenced in `PortBindingsServiceProvider` |
| V — Schema owned by migrations | `infra` has no `CREATE TABLE` | Same: `infra` only starts an empty PostgreSQL |
| VI — DB enforces what it can | `data-model.md` §10 queries | Same queries run against the migrated database |
| VII — Derived values computed | No `status` / `days_late` columns | Same: computed in the domain / query |
| IX — No secrets in repo | gitleaks / grep | Same; `.env` ignored, only `.env.example` versioned |

## 4. Laravel-specific rules that protect the data model

- Remove Laravel's default migrations (`users`, `password_reset_tokens`, `sessions`, `cache`, `jobs`). The data model has exactly six tables.
- Models use `public $timestamps = false;` — the data model has no `created_at` / `updated_at`.
- No `->default()` in migrations — "no column has a `DEFAULT`".
- UUIDs are generated by the application as **v4** (`Str::uuid()`), not by the database.
- Every error goes through one renderer that returns `{ "code", "message", "details" }`; 401/403 are JSON, never redirects.
- Pagination returns `{ "items", "page", "size", "total" }`, not Laravel's default paginator shape.
